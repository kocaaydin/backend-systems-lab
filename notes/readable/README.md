
# 📚 Backend Systems Lab - Study Notes Index

Bu klasör, backend mülakatlarına ve sistem tasarımı çalışmalarına yönelik notların **kolay okunabilir** parçalara bölünmüş halini içerir.

## 📂 İçerik Yapısı

Her klasörde iki dosya bulunur:
- **Detailed:** Konu anlatımı ve **kod örnekleri** içerir.
- **Cheatsheet:** Sadece başlıklar ve anahtar kelimeler (Hızlı tekrar için).

### 1️⃣ [Data Structures & Algorithms](./01-DataStructures_Algorithms/)
- **İçerik:** Array, List, Stack, Queue, Hash Table, Tree, Graph, Sorting, Searching.
- **Odak:** Big-O, Zaman/Uzay karmaşıklığı, Temel mülakat soruları (Two Sum vb.).

### 2️⃣ [Design Patterns](./02-DesignPatterns/)
- **İçerik:** Creational (Singleton, Factory...), Structural (Adapter, Decorator...), Behavioral (Strategy, Observer...).
- **Odak:** Hangi pattern hangi sorunu çözer?

### 3️⃣ [C# & .NET](./03-CSharp_DotNet/)
- **İçerik:** CLR, Memory Management (GC), Async/Await, LINQ, OOP, Collections.
- **Odak:** .NET Runtime derinlikleri ve C# mülakat soruları.

### 4️⃣ [Architecture & System Design](./04-Architecture_SystemDesign/)
- **İçerik:** SOLID, Distributed Patterns (Circuit Breaker, Saga...), Caching, REST API, Security.
- **Odak:** Sistem tasarımı ve mimari kararlar.

### 5️⃣ [Databases](./05-Databases/)
- **İçerik:** MSSQL (Indexing, isolation...), MongoDB (Modeling...), Elasticsearch (Searching...).
- **Odak:** Veritabanı optimizasyonu ve doğru DB seçimi.

### 6️⃣ [DevOps & Messaging](./06-DevOps_Messaging/)
- **İçerik:** Docker, Kubernetes, RabbitMQ, Kafka.
- **Odak:** Container yönetimi ve asenkron iletişim patternleri.
